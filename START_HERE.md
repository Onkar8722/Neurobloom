## 🚀 How to Start

### Option 1: 5-Minute Quick Start
Read **QUICKSTART.md** then:
```bash
# Terminal 1: Backend
cd neurobloom-backend
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python run.py

# Terminal 2: Frontend
cd neurobloom-frontend
npm install
npm start
```
Visit http://localhost:3000

### Option 2: Detailed Setup
Follow **INSTALLATION.md** step-by-step

### Option 3: Learn First
Read **README.md** and **DEVELOPMENT.md** first
